# 頭痛LP（ひなた整骨院）

`lp/zutsuu/index.html` … 頭痛・肩こり向けのランディングページ（1ファイル完結・スマホ最適化）。
ブラウザでそのまま開けます。Vercel等にそのまま置いてもOK。

## 構成
FV（キャッチ＋CTA）→ 悩みチェック → 共感 → 根本原因3つ → 選ばれる理由4つ →
施術の流れ → お客様の声 → 初回キャンペーン料金 → 院長あいさつ → FAQ → アクセス → 最終CTA

- ターゲット：40〜50代女性（頭痛・肩こり・猫背）
- 医療的な断定表現（治る・完治・必ず）は使わず「改善を目指す」トーンに統一
- 電話（044-387-1861）はタップ発信、LINEは `index.html` 末尾の `LINE_URL` に公式URLを設定すると有効化
